# FastMD Store Installer

Download **FastMD.Installer.exe** below to install FastMD through Microsoft Store.
Microsoft Store supplies the version currently available to your account and
device and handles subsequent updates. Microsoft Store access is required.

This permanent launcher is independent of FastMD application version releases.
It is not a standalone or offline FastMD package.

Each GitHub version release also attaches a copy of this launcher,
`FastMD.Installer.exe`, and portable ZIPs for x64 and arm64, from the
[latest GitHub release](https://github.com/skypediacode/fastmd/releases/latest).
Windows SmartScreen can warn about downloaded programs that are not code-signed
yet, including the portable executable. If that happens, select **More info**,
then **Run anyway**.

You can also [open FastMD in Microsoft Store](https://apps.microsoft.com/detail/9N4DSD4WNZ9D).
