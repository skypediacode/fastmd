# FastMD Store Installer

Download **FastMD.Installer.exe** below to install FastMD through Microsoft Store.
Microsoft Store supplies the version currently available to your account and
device and handles subsequent updates. Microsoft Store access is required.

This permanent launcher is independent of FastMD application version releases.
It is not a standalone or offline FastMD package. Future GitHub version releases
contain notes without new application installer or portable assets.

You can also [open FastMD in Microsoft Store](https://apps.microsoft.com/detail/9N4DSD4WNZ9D).
