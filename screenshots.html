FastMD in Action

Real captures of FastMD 3.7.0 on Windows: one writing workspace and four focused feature views. Click any image to inspect the full-size capture.

Writing workspace

Markdown source and live preview

A native file tree and document outline sit beside Markdown source, rendered callouts, task lists, tables, and highlighted code.

Math and chemistry

Readable notation, rendered locally

LaTeX equations and a balanced mhchem reaction appear beside their editable Markdown source.

Mermaid diagrams

Turn a process into a diagram

An offline Mermaid flowchart renders in the live preview while its source remains editable.

Interactive mind map

Explore the structure of a document

FastMD builds a navigable mind map from Markdown headings. Double-click a node to return to its source.

Command palette

Find a command from the keyboard

Press F1 to search application commands and see their keyboard shortcuts without leaving the document.
